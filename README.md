# NOOR — الكود المصدري الكامل 🌙

منصة إسلامية متكاملة: المصحف الشريف، الأذكار، مواقيت الصلاة، القبلة، التسبيح، التقويم الهجري، الزكاة، دليل الحج، القصص، المجتمع، المساعد الذكي، والألعاب.

*التطبيق المباشر:* https://holyquran2.base44.app
*المنصة الأصلية:* Base44 — منشأ بواسطة محمد الحجري
*تاريخ النسخ:* 26 سبتمبر 2026

## محتويات المستودع

1. `src/` — الكود المصدري الكامل (162 ملفاً): الصفحات، المكونات، الأنماط، البيانات، الخدمات
2. `base44/` — إعدادات المنصة: الكيانات، الدوال الخلفية (مزامنة مواقيت الصلاة مع تقويم جوجل، مؤذن الأذان المجدول)، الموصلات
3. `published-build/` — نسخة من الحزمة المنشورة الجاهزة (للمعاينة فقط)
4. ملفات الإعداد: package.json، vite.config.js، tailwind.config.js وغيرها

1. كلمات المرور والمفاتيح السرية استُبدلت بـ `REMOVED_SECRET` قبل الرفع لأمانك.
2. استُخدمت صفحة تصدير مؤقتة لسحب الكود، ثم أزيلت من التطبيق الأصلي.
3. التطبيق مبني بـ React + Vite + Tailwind عبر حزمة SDK الخاصة بـ Base44.
