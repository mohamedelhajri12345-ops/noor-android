# تطبيق نور (NOOR) - تطبيق إسلامي شامل

تطبيق إسلامي أصلّي لنظام أندرويد تم بناؤه باستخدام Kotlin و Jetpack Compose و Material3.

## تعليمات التشغيل والبناء

### 1. المتطلبات الأساسية
- **Android Studio**: إصدار Hedgehog (2023.1.1) أو أحدث.
- **Android SDK**: Compile SDK 34, Min SDK 24.
- **JDK**: Java 17 أو أحدث.

### 2. فتح المشروع
1. افتح تطبيق Android Studio.
2. اختر **Open** وانتقل إلى مجلد المشروع `/tmp/noor-android`.
3. انتظر حتى ينتهي Android Studio من مزامنة ملفات Gradle (`Sync Project with Gradle Files`).

### 3. بناء وتشغيل التطبيق
- **التشغيل عبر Android Studio**:
  - حدد الجهاز أو المحاكي (Emulator) في شريط الأدوات العلوي.
  - انقر على زر التشغيل **Run** (أو اضغط `Shift + F10`).

- **البناء من خلال السطر البرمجي (Terminal)**:
  ```bash
  ./gradlew assembleDebug
  ```
  *ملاحظة:* البناء لأول مرة سيقوم بتنزيل مكتبات Gradle وجميع الاعتماديات المطلوبة، مما قد يستغرق بعض الوقت بناءً على سرعة الاتصال بالإنترنت.

---

### ملاحظات تقنية
- **بدون WebView**: التطبيق مصمم ومبني كلياً باستعمال واجهات أندرويد الأصلية Native (Jetpack Compose) ولا يحتوي على أي مكون WebView على الإطلاق.
- جميع بيانات الأذكار والسور والمؤذنين والأسئلة محملة محلياً ودون الحاجة لاتصال بالإنترنت من المجلد `assets/data/`.
